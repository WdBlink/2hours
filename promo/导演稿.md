# Two Hours 首支演示片导演稿

已批准方向：B「2h」单色标识 + A 连续纸面镜头。本片 55 秒、1920×1080、60fps，字幕主导，无真人录音；原创程序化配乐与轻交互音效。

主张：把工作进展与收藏资料整理成一份可读报告，在同一份报告上表达判断，核对理解与去向后一次确认，回到原上下文继续工作。不承诺两小时收益、持久后台唤醒或自动完成任务。

## 视觉与真实性约束

全片沿一份纸面报告连续推进。背景是制作时的纸白与细网格，真实 UI 来自仓库 examples/review，由当时的产品 renderer 渲染。所有任务、数字、源材料和去向均为虚构。录音、发送、真实会话和私有运行目录不进入采集链。来源归并和回执为明确标注的叙事图形，不能冒充产品现有界面。

主角为同一份报告；景深由纸张阴影与尺寸关系建立。每帧最多三个活跃元素。正文 UI 不重画；只放大真实截图，镜头与圈画分层。1080p 主标题 42–64px，短字幕 30px，演示提示 20px。关键信息距边缘至少 90px。图形运动为确定性时间函数；不使用随机数、异步计时器控制画面状态。

## 声音与密度

原创五声音阶钟琴/Rhodes 式柔和音色，四组和弦循环，低频与音量保持克制；口述字幕段降低伴奏。SFX 仅放在调用、开页、画圈、勾选、确认与回执点，不做持续机械噪声。所有声音由 numpy 按固定参数生成，无外部采样授权问题。

不会用空镜拖时长：真实 UI 从第一帧就存在；每段都有可读信息和至少一个可见状态变化。圈画、光标与纸面连续运动服务注意力，不让整屏抖动。产品阅读停顿允许低帧差，QA 数字必须结合时刻亲眼复核，不能将刻意阅读停顿伪称卡顿修复。

## 独立审片后的定点修订

保持 55 秒结构。来源区明确写 Cubox 收藏（虚构示例）；来源文字退出之后才放大报告。详情与流程图只通过截图滚动和镜头裁景，完整保留图下注释。口述字幕与审核原话逐字一致，任务指令仍可改写。整理阶段使用已有的文字意见已提交状态，脚本用户明确在口述后保存相同原话并添加 A5 的文字意见，两个来源都可见；不表示口述自动写入文字意见。A5 审核来源标签为文字批注。
